
# Student Marks Analyzer

A beginner-friendly Python project that analyzes student marks using NumPy.

## Project Overview

This project generates sample marks for 50 students across 5 subjects and analyzes their academic performance using NumPy arrays.

## Features

- Generates sample student marks.
- Calculates subject-wise and student-wise averages.
- Identifies subject-wise toppers.
- Detects marks below 40 and above 90.
- Calculates subject-wise pass percentages.
- Categorizes marks into grade bands.
- Demonstrates NumPy array properties, slicing, and Boolean masking.

## Technologies Used

- Python
- NumPy
- Google Colab

## How to Run

1. Open the notebook in this repository.
2. Click "Open in Colab" if the link is available, or upload the notebook to Google Colab.
3. Run the code cells from top to bottom.
4. Review the generated performance report.

## Dataset

The project uses randomly generated sample marks.
It does not contain real student records.
